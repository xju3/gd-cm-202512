# 4G小区运行状态异常（整站退服）处理方案
## 一、安全准备
1. 备件

    1. 临时电缆若干；
    2. 发电机
2. 工具
        
    1. 基础维修工具：十字/内六角螺丝刀套装、扳手；
    2. 安全检测工具：钳表(测量电压)、验电笔（确认设备断电状态）、绝缘手套（防触电）；
    3. 安全防护工具：安全帽、绝缘鞋、。

3. 业主沟通
        
    1. 移动代维立即与业主（铁塔公司/机房产权方）取得联系，说明故障原因：基站设备故障导致高速路段4G小区退服，需进站处理故障作业，申请进站作业许可，明确进站时间、作业区域（机房BBU区、RRU安装点位）；

4. 安全准备
       
    1. 作业前工具校验：钳表、验电笔开机自检正常，绝缘工具无破损开裂，确保工具安全有效；
    2. 人员分工：1人进行电压测量，另一人在旁边监督；
    3. 环境排查：如确定需要发电作业，需确保周边没有杂物等易燃物品，做好围蔽等操作；
    4. 安全规范：发电作业时需按先验电后送电、供电作业时，需按逐一送电原则进行供电。

5. 校验确认
        
    1. 工具功能测试：钳表、验电笔可准确识别带电状态，螺丝刀、扳手等工具无破损、无锈蚀；
    2. 辅助条件确认：现场有足够的发电条件。

## 二、现场操作步骤

1. 进站与故障定位

    1. 作业人员到达现场后先查看周边供电是否异常，同步到电表或设备位置测量是否有电到；
    2. 初步检测：现场确认周边停电且电表位置测量无电压，安排发电作业。

2. 发电前操作
        
    1. 发电区域进行围蔽，警示；
    2. 断开市电供电线路，断开设备供电并接入油机发电；。

3. 来电后操作
        
    1. 断开负载并重新接入市电，测量电压稳定后再逐级进行供电；
    2. 恢复供电：再次核对开关标识无误后，合上RRU电源开关（或闭合空开），记录通电时间；
    3. 启动观察：观察BBU侧RRU光口启动过程，指示灯应依次亮起并进入正常状态（电源灯常亮，链路灯闪烁），记录启动完成时间（约3-5分钟）。

4. 业务验证
        
    1. 设备状态核查：登录ENodeB设备管理系统，查看RRU运行状态显示“正常”，无相关告警信息；再次观察RRU指示灯，确认符合正常运行标准；
    2. 告警清除：在网管系统中清除“4G小区运行状态异常”告警，重启故障EUtranCellTDD小区（FSCCNanZhuangChanGXLLJDF-ELH-2），观察ENodeB管理状态显示“正常”；

5. 收尾工作
        
    1. 工具整理：收拾现场发电油机；
    2. 环境恢复：清洁作业区域，确保现场环境整洁；

## 三、故障处理闭环归档

1. 工单归档
        现场处理完成后，登录掌上运维故障工单系统（工单号：CMCC-GD-GZCL-20251211-002337），查看告警是否消除，详细填写处理记录进行回单。

2. 油机退仓
        本次故障为市电停电导致设备退服，发电后需把油机退回仓库保管，如存在未用完的汽油，需要提前清理。

3. 应急预案优化
        
    1. 经验总结：涉及市电导致的整站退服，必须携带发电油机一起到现场，减少核实市电后返回领取油机的操作，减少退服时长；
    2. 响应机制优化：完善RRU故障分级响应标准，针对设备整站退服类故障，明确各环节时间节点，确保业务快速恢复；
    3. 监控体系升级：建议在网管系统中增加RRU运行状态实时监测功能，新增“RRU无响应”专项告警（当RRU与BBU通信正常但设备状态异常超过5分钟时触发），实现故障提前预警；
    4. 维护优化：建立RRU设备周期性维护机制，每半年开展1次预防性断电重启（避开业务高峰时段），降低程序卡死概率；针对爱立信RBS6601配套RRU型号，定期核查设备固件版本，及时升级优化存在的程序漏洞；每月通过网管系统核查RRU运行日志，排查潜在异常风险。
